# Рабочий журнал

## Решения

- Серию дней считаю без загрузки всей истории, чтобы уложиться в лимит памяти 96 МБ.
- В расчёте интервалов исправил ситуацию, когда карточка навсегда оставалась на ежедневном повторении.
- На публичной странице оставил только статистику, а API можно закрыть токеном.
- Для CI закрепил совместимую версию Ubuntu, поскольку обновление Playwright затронуло бы привязку к драйверу.

## Допущения

- Не совсем понятно было, что значит «сколько повторить за неделю». Я понял это как количество предстоящих повторений.
- Выученными считаю карточки, которые не нужно повторять ближайшие три недели.
- Также исходил из одного пользователя, а границы дня определял по часовому поясу сервера.

## С чем поспорил / что отклонил

- Не стал делать удаление заметок через 30 дней, потому что они нужны для долгосрочного запоминания.
- Отказался от конспектов через ИИ: здесь полезнее самостоятельно формулировать мысли, а личные записи не хотелось передавать стороннему сервису.
- Обложки книг и цитату дня посчитал необязательными для основной задачи, а автословарь слишком сильно расширяет объём проекта.

## Мнение

- На мой взгляд, получилось достаточно простое решение для личного использования. Есть что улучшить: добавить связи между заметками в интерфейсе, выбор часового пояса и более строгие тесты.
